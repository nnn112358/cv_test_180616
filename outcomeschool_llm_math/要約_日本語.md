## 1. アテンションの数学：Q・K・V
原文: https://outcomeschool.com/blog/math-behind-attention-qkv

- 式: `Attention(Q, K, V) = softmax(Q·Kᵀ / √dₖ) · V`
- 手順:
  1. 単語を埋め込みベクトルにして、入力行列 X を作る（例は「I love AI」の3語×4次元）。
  2. X に学習済みの重み行列 W_Q、W_K、W_V を掛けて、Q、K、V を作る（例では dₖ = 3）。
  3. `Q·Kᵀ` で各単語ペアの関連度スコアを計算する（例では「I」が「love」に最高スコア5を与える）。
  4. √dₖ で割ってスケーリングする。スコアの順位は変わらず、値だけが小さくなる。
  5. softmax で重み（合計1）に変換する。
  6. 重みで V を加重平均し、各単語の出力ベクトルを得る。
- 要点: 「探しているもの（Q）」と「提供するもの（K）」を照合し、関連が強い単語の情報（V）を多く取り込む。

## 2. なぜ √dₖ でスケーリングするのか
原文: https://outcomeschool.com/blog/scaling-dot-product-attention

- ドット積は dₖ 個の項の和なので、次元が大きいほど値の振れ幅が大きくなる。
- q と k の各要素が平均0・分散1で独立だと仮定すると、各積 qᵢkᵢ の分散は1になる。和の分散は **dₖ**、標準偏差は **√dₖ** になる。記事では (a+b+c)² の展開を使って、これを一歩ずつ証明している。
- スコアが大きすぎると、softmax の出力がほぼ0か1に偏る（飽和する）。勾配が消えて学習が進まなくなる。
- √dₖ で割ると分散が1に戻り、softmax が健全な範囲で動く。
- 補足: softmax の出力は合計が必ず1になるため、どのトークンにも注目すべきでない場合でも注意をどこかに配分しなければならない（Attention Sink の話につながる）。

## 3. 誤差逆伝播（バックプロパゲーション）の数学
原文: https://outcomeschool.com/blog/math-behind-backpropagation

- 名前のとおり「誤差を後ろ向きに伝える」方法。各重みが誤差にどれだけ寄与したかを計算する。
- 例え: 先生が答えの誤りを指摘するだけでなく、解き方をさかのぼって間違えた箇所を特定するようなもの。
- **連鎖律**: `dz/dx = dz/dy · dy/dx`。依存関係の連鎖をたどって変化率を求める。
- 順伝播: 加重和 `z = w·x + b` を計算し、活性化関数（シグモイド）に通す。非線形性があるから複雑なパターンを学習できる。
- 損失: 二乗誤差 `L = ½(y − ŷ)²`。½ は微分を簡単にするための定数。
- 逆伝播: 入力 → 隠れ層 → 出力の小さなネットワークで、`dL/dw2` と `dL/dw1` を連鎖律で数値的に求める。
- シグモイドの微分は `σ(z)(1 − σ(z))` と自分自身の出力で書ける。順伝播で計算した値をそのまま再利用できる。
- 求めた勾配を使って、勾配降下法で重みを更新する。

## 4. 勾配降下法の数学
原文: https://outcomeschool.com/blog/math-behind-gradient-descent

- 損失関数: 予測がどれだけ外れているかを測る関数。代表例は平均二乗誤差（MSE）。二乗すると誤差が必ず正になり、大きな誤差ほど強く罰せられる。
- 直感: 霧の山で足元の傾きだけを頼りに谷底へ下りていく。傾きが急なら大きく、緩やかなら小さく進む。
- 更新式: `w_new = w_old − α · dL/dw`（α は学習率）。マイナス符号のおかげで、常に下り方向へ進む。
- 数値例: `L = (w − 3)²`、w = 0、α = 0.1 から始めると、w が少しずつ3に近づき、勾配と歩幅も小さくなって収束する。
- 重みが複数ある場合は偏微分を使う（テレビの音量と明るさのつまみを1つずつ回して効果を見るようなもの）。各重みを同時に更新する。
- 記事では学習率の選び方、バッチ／確率的／ミニバッチの違いにも触れている。

## 5. 交差エントロピー損失の数学
原文: https://outcomeschool.com/blog/math-behind-cross-entropy-loss

- 予測した確率分布が正解からどれだけずれているかを表す数値。小さいほど良い。
- 例え: 天気予報士が「雨60%、晴れ30%、雪10%」と予報し、実際に起きた天気で採点する。モデルが予報士、softmax の出力が予報、正解ラベルが実際の天気にあたる。
- 流れ: ロジット → softmax で確率に変換 → 正解クラスの確率の負の対数を取る。
- 式: `CE = −Σ yᵢ log pᵢ`。one-hot ラベルなら `−log(p_正解)` になる。
- なぜ負の log か: 確率が1/10になるごとに罰則が一定量（約2.303）増える。「自信満々に間違える」ことを強く罰するためで、log(0〜1) は負なので符号を反転する。
- 二値の場合: `BCE = −[y log p + (1−y) log(1−p)]`（例: y = 1 で p = 0.8 なら損失は小さく、p = 0.2 なら大きい）。
- 多クラスの場合は、one-hot ベクトルと softmax 出力で計算する。

## 6. RoPE（回転位置埋め込み）の数学
原文: https://outcomeschool.com/blog/math-behind-rope-rotary-position-embedding

- Transformer は全トークンを並列に処理するので、そのままでは語順がわからない。
- 従来手法（絶対位置の正弦波エンコーディングや学習型位置埋め込みの加算）には、長い系列への汎化などの課題がある。
- RoPE の考え方: 位置ベクトルを足す代わりに、Q と K を位置に比例した角度だけ**回転**させる。
- 2次元の回転行列 `[[cosθ, −sinθ], [sinθ, cosθ]]` はベクトルの長さを変えず、向きだけを変える。
- 高次元の Q/K は2次元ずつのペアに分け、各ペア i を位置 m に応じて `m·θᵢ` だけ回す。`θᵢ = 10000^(−2(i−1)/d)` なので、前のペアほど速く、後ろのペアほどゆっくり回る（速さの違う時計の針のようなもの）。
- 核心: `(R_m Q)·(R_n K) = Q·R_(n−m) K` となり、注意スコアは**相対距離 n − m だけ**に依存する。相対位置の情報がドット積から「タダで」手に入る。
- 長さも変えないので学習が安定しやすく、多くの現代 LLM で採用されている。

## 7. RMSNorm（二乗平均平方根レイヤー正規化）
原文: https://outcomeschool.com/blog/rmsnorm-root-mean-square-layer-normalization

- 深い層を通るうちに値が爆発したり消えたりするのを防ぐため、各層で値を正規化する。
- LayerNorm: `γ·(x − 平均)/√(分散 + ε) + β`。中心化とスケーリングの両方を行う。
- RMSNorm（Zhang & Sennrich, 2019）: 平均を引く処理を省き、スケーリングだけを行う。
  - `RMS(x) = √(mean(x²))`
  - `RMSNorm(x) = γ · x / √(mean(x²) + ε)`。β は不要。
- 平均のずれは、残差接続や学習済みの射影が吸収できるため、精度を落とさずに計算量を減らせる。
- γ は、全ベクトルが一定の大きさに固定されるのを避け、次元ごとに適切なスケールへ戻すための調整つまみ。
- Llama、Mistral、Gemma、Qwen、PaLM、DeepSeek など多くの LLM が採用している。高速でシンプルなのに、効果は同等。
