制御工学 ・ 最適制御（LQR）

リッカチ方程式

台車を原点に戻すとき、ずれと力のコスト J = ∫(xᵀQx + uᵀRu)dt を最小にしたい。最小コストは V(x) = xᵀPx という「お椀」の形をしていて、そのお椀の形 P を決めるのがリッカチ方程式です。
AᵀP + PA − PBR⁻¹BᵀP + Q = 0
放っておいたときの変化制御で減らせる分払うコスト

1お椀の形 P を、時間をさかのぼって求める

終わりの時刻から逆向きに −Ṗ = AᵀP + PA − PBR⁻¹BᵀP + Q を解くと、P は一定値に落ち着く。

2お椀を下るのが最適制御

力は u = −Kx（K = R⁻¹BᵀP）。下る速さと払うコストが常に釣り合う。それがリッカチ方程式の意味。

00
例：台車（2重積分器）A = [[0, 1], [0, 0]], B = [0, 1]ᵀ, Q = diag(1, 1), R = 0.5。図の数値はすべて式から計算（RK4）。
