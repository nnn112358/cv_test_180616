リッカチ方程式

「どれだけ早く目標に戻すか」と「どれだけ力を使うか」。この2つの釣り合いを、ひとつの行列 P に閉じ込めたのがリッカチ方程式です。動く図で、何が釣り合っているのかを順番に見ていきます。

ATP + PA − PBR−1BTP + Q = 0
放っておいたときの変化（ドリフト）制御で減らせる分払うコスト
すべての図がループ再生されます
1

何を最小にしたいのか

例として、摩擦のないレールの上の台車を考えます。状態は位置と速度、入力 u は台車を押す力です。

ẋ = Ax + Bu A = 0100,  B = 01 x = (位置, 速度)
u = 力

評価するのは、ずれと力の「2乗の積分」です。Q はずれに対する罰、R は力の使いすぎに対する罰で、この2つの重みの比が制御の性格を決めます。

J = ∫0∞ ( xTQx + uTRu ) dt  → 最小
2

方程式は「コストの収支」を表している

状態 x から出発したときの最小コストは、2次形式 V(x) = xTPx で書けます。最適な入力は、このお椀を一番急に下る向き u = −R−1BTPx です。

最適な軌道の上では、「お椀を下る速さ」と「その瞬間に払うコスト」がちょうど打ち消し合います。この打ち消し合いが、どの x でも成り立つ条件を書き下すと、リッカチ方程式になります。

xT(ATP + PA)x − 2xTPBR−1BTPx + ( xTQx + uTRu ) = 0
3

1次元で見ると、ただの2次方程式

状態が1つなら、P は数 p になり、リッカチ方程式は p の2次方程式 2ap − b2p2/r + q = 0 です。根は2つありますが、意味があるのは正の根だけです。

終端から時間をさかのぼって p を動かすと（次の節の微分形）、どこから始めても正の根に吸い寄せられます。だから、この根が「長い時間で見たときの答え」になります。

4

終端から時間をさかのぼって解く

終わりの時刻 T がある問題では、P は時間とともに変わり、微分形のリッカチ方程式に従います。終端条件 P(T) から出発して、時間を逆向きに積分します。

−Ṗ = ATP + PA − PBR−1BTP + Q,   P(T) = 0

さかのぼる時間が長くなると P(t) は一定値に落ち着きます。その一定値が、冒頭の代数リッカチ方程式（Ṗ = 0 とおいた形）の解です。

p₁₁p₁₂p₂₂
5

重みを変えて、解の変化を見る

スライダーで Q と R を変えると、その場でリッカチ方程式を解き直し、ゲイン K = R−1BTP と応答を描き直します。この台車の例では、解を式で書けます。

p₁₂ = √(q₁r),   p₂₂ = √(r(2p₁₂ + q₂)),   p₁₁ = p₁₂p₂₂ / r
6

まとめ

  • ATP + PA は、入力がないときにシステム自身の動きで V がどう変わるかを表します。
  • −PBR−1BTP は、最適な入力で V をどれだけ減らせるかを表します。R が大きいほど小さくなります。
  • Q は、ずれに払うコストの割合です。
  • この3つの和がゼロになる P を求めれば、最適なフィードバック u = −R−1BTPx がそのまま決まります。
