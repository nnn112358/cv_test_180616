# cv_test_180616

## index.html — ぶつかるたびに分裂するボール

じゃがりきん氏の投稿（[@jagarikin](https://x.com/jagarikin/status/2097409553281499469)）の
「ぶつかるたびに分裂するボール」を HTML + Canvas で再現したもの。
`index.html` をブラウザで開くだけで動く（依存ライブラリなし）。

### ルール

- 円形のアリーナの中をボールが一定の速さで動き、壁では完全反射する。
- ボール同士が衝突すると、その 2 個がそれぞれ 2 個に分裂して 4 個になる。
- 分裂した直後は 0.14 秒だけ再分裂しない（生まれた瞬間の連鎖分裂を防ぐため）。
- 衝突のたびに個数が増えるので、密度が上がるほど衝突が増え、指数関数的に増える。

### 元動画から実測した値

| 項目 | 値 |
| --- | --- |
| 描画サイズ | 700 × 488 px |
| アリーナ中心 / 半径 | (352, 241) / 171 px |
| ボール半径 | 7 px |
| ボールの速さ | 約 143 px/秒 |
| 配色 | `#62deff` / `#ffdd93`（輪郭は各色の暗色） |

### 操作

- 再生 / 一時停止（Space）、リセット（R）
- 「最初の衝突まで進める」: 初手の衝突は 30 秒以上かかることがあるので早送りする
- 速度、ボール半径、分裂の開き角、最大個数のスライダー
- 「分裂で小さくなる」: 分裂のたびに半径を 1/√2 倍し、総面積を一定に保つ。
  アリーナが埋まらないので数千個まで増やせる。

### 実装メモ

- 位置・速度は Float64Array（SoA）で保持し、衝突判定は毎ステップ計数ソートで
  作り直す固定セルの空間グリッドで行う。
- 物理は 1/120 秒の固定ステップ。個数が増えるほど 1 フレームあたりのステップ数を
  絞り、フレームレートではなく体感速度を落とす。
- 速度の大きさは毎ステップ一定に正規化する。密集時にエネルギーが暴走しない。
